# Supermarket Sales Analysis

A beginner-friendly **Data Analytics project** that analyses 500 supermarket sales transactions to find useful information about products, branches, categories, customers, payments and ratings, and converts the results into business decisions.

## Dataset

- **Source (Google Sheet):** https://docs.google.com/spreadsheets/d/1QIX__4VObHFMEXnRM2xJyXmB5JAB2peHrJcQ41_U9TE/edit?usp=sharing
- **Local copy:** `SUPER_MARKET_DATA.xlsx` (sheet `supermarket_sales_500_rows`)
- **Size:** 500 rows × 13 columns, 1 Jan 2026 – 1 Jul 2026

| Column | Description |
|---|---|
| Invoice ID | Unique transaction ID |
| Date | Date of sale |
| Branch / City | Store branch (A–D) and its city (Jaipur, Delhi, Mumbai, Bengaluru) |
| Customer Type | Member or Normal |
| Gender | Female or Male |
| Product / Category | 20 products across 8 categories |
| Quantity, Unit Price | Units bought and price per unit (₹) |
| Payment | UPI, Net Banking, Card or Cash |
| Rating | Customer rating (3.0 – 5.0) |
| Sales | Quantity × Unit Price (₹) |

## Project Description

The analysis answers six business questions:

1. Which product generates the highest sales?
2. Which branch performs best?
3. Which category sells the most?
4. What is the most popular payment method?
5. Do Members spend more than Normal customers?
6. What is the average customer rating?

**Steps:** load data → check for missing/incorrect values → validate `Sales = Quantity × Unit Price` → group and summarise → visualise → business decisions.

## Key Findings

| Question | Answer |
|---|---|
| Top product | Cheese — ₹27,906.30 |
| Best branch | Branch C (Mumbai) — ₹72,469.45 |
| Top category | Beverages — ₹56,108.24 |
| Popular payment | UPI — 127 transactions |
| Members spend more? | No — Member ₹483.14 vs Normal ₹497.07 (difference not statistically significant) |
| Average rating | 3.99 / 5 |

Total sales: ₹244,411.08 across 500 transactions. Data quality was clean (no missing values or duplicates). July 2026 contains only one day of data, so it is a partial month.

## Setup and Run Instructions

```bash

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch Jupyter and open the notebook
jupyter notebook SaiKiranIppili_SupermarketSalesAnalysis.ipynb
```

Keep `SUPER_MARKET_DATA.xlsx` in the same folder as the notebook, then choose **Kernel → Restart & Run All**. Charts are saved automatically to the `charts/` folder.

**Google Colab:** upload the notebook and `SUPER_MARKET_DATA.xlsx` to the Colab Files panel and run all cells (all libraries are pre-installed).

## Business Recommendations (summary)

- Stock more of Cheese, Coffee, Shampoo, Cooking Oil and the Beverages / Personal Care / Dairy categories.
- Study Branch C's practices and apply them at Branch A.
- Keep all payment channels; promote UPI.
- Raise service quality, starting with Branch A (lowest rating, 3.84).
- Redesign membership offers around higher basket sizes.
